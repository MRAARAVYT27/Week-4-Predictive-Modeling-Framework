# Week 4: Predictive Modeling Framework for Wheat Yield Prediction

## Project Overview

This project proposes a machine learning framework for predicting wheat crop yield using agricultural and environmental data. The objective is to outline a systematic workflow for preparing data, selecting relevant features, training regression models, and evaluating their performance.

## Problem Statement

Crop yield forecasting can help agricultural stakeholders plan resources, estimate expected production, and make better-informed decisions. The proposed framework focuses on predicting wheat yield in tonnes per hectare using relevant historical agricultural data.

## Proposed Methodology

1. Define the prediction target and intended use.
2. Identify a suitable agricultural dataset.
3. Inspect and preprocess the data.
4. Select relevant features, such as rainfall, temperature, cultivated area, and historical yield, where available.
5. Split the data into appropriate training, validation, and test sets.
6. Establish a baseline and evaluate candidate regression algorithms.
7. Compare models using MAE, MSE, RMSE, and R².
8. Document limitations, potential errors, and future improvements.

## Candidate Algorithms

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

These algorithms are proposed candidates. The final model will be selected only after evaluation.
